# OryphemRouter — Agent Guidelines

This file is read by AI coding agents (Claude Code, Codex, OpenCode, Cursor, etc.) at session start.

## Anti AI Slop (mandatory)

> Read `skills/antislop/SKILL.md` and follow its rules for **all** UI, copy, and design work in this project. The goal: output feels crafted by a designer, not generated by AI.

**Skills available (load only what the task needs):**

| Skill | When to load |
|-------|--------------|
| `skills/antislop/SKILL.md` | Always — core filter (rules, tiers, Delivery Gate) |
| `skills/antislop-ui/SKILL.md` | Building or editing UI/visual: layout, color, components, motion |
| `skills/antislop-copywriting/SKILL.md` | Writing or editing copy: headlines, CTAs, tone, landing pages |
| `skills/antislop-human/SKILL.md` | Accessibility: contrast, keyboard, focus, states |
| `skills/antislop-layoutmobile/SKILL.md` | Mobile layout: breakpoints, grids, tap targets, nav |

Before any UI work, ask the user (in their chat language) whether antislop applies **during** the work or **after** it is done. Do not start until they answer.

## Project conventions

- **Runtime**: Node.js 20+, Next.js 16, React 19, Tailwind CSS 4
- **Dual language UI**: English (default) + Indonesian (`src/i18n/`)
- **Default port**: 20129
- **Default dashboard password**: `123` (not 123456)
- **Data dir**: `~/.oryphemrouter/` (macOS/Linux) or `%APPDATA%\oryphemrouter\` (Windows)
- **Docker image**: `ghcr.io/virgiawanprima/oryphemrouter:latest`
- **OAuth credentials**: load from env vars (`GOOGLE_OAUTH_CLIENT_ID`, `ANTIGRAVITY_OAUTH_CLIENT_ID`, ...) — never hardcode secrets

## Git & security discipline

- **Atomic & Conventional Commits**: one logical change per commit; use `feat:`, `fix:`, `test:`, `docs:`, `chore:`, `refactor:`, `ci:` prefixes.
- **Staging presisi**: `git add <file>` for relevant files only — never `git add -A` blindly.
- **Zero-trust**: scan for secrets/tokens/`.env` before any commit. Never commit secrets.
- **Author**: `virgiawanprima <virgiawanprimarizky@gmail.com>`
